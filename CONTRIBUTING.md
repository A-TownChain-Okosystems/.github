# Contributing (.github Hub)

Dieser Hub ist die Organisations-Control-Plane der A-TownChain-Okosystems.

- **Aenderungen nur via Pull Request** (Branch-Protection hart, GH006) mit Owner-Review; Agenten sind Executor/Auditor/Maintainer, niemals Approver (ATC-STD-003 par.9).
- **Standards-SSOT:** atc-standards/registry/standards.yaml; Zahlen im Hub werden referenziert, nie dupliziert.
- **Agent-Aenderungen** tragen den [agent: ...]-Commit-Trailer und werden im SCR-/Findings-Register dokumentiert.
- **Org-Compliance-Scan** laeuft woechentlich (org-compliance-scan.yml); Findings gehen ins findings.yaml.
