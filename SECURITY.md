# Security Policy

Sicherheitsprobleme werden NICHT ueber oeffentliche GitHub Issues gemeldet.

1. **Private Vulnerability Reporting** (GitHub Security-Tab) verwenden.
2. Fuer ATC-Protokoll-/Konsens-Schwachstellen gilt zusaetzlich ATC-STD-PROTOCOL-003 (Protocol Threat Model) und ATC-STD-020 (Incident Response, SEV-1..4).
3. disclosure: nach Behebung + Koordinierung mit dem Owner (Michael Wroblewski).

Dieser Hub ist die Organisations-Control-Plane (Agent-Governance, Org-Compliance-Scan). Aenderungen nur via PR mit Owner-Review (ATC-STD-003 par.9: Agenten sind nie Approver).
